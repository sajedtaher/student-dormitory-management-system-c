# Student Dormitory Management System (C)

A console-based student dormitory management system developed in C.

## Features

* Add new student records
* Delete student records
* Update student information
* List all students alphabetically
* Track rent debts
* Track electricity debts
* Pay rent debt
* Pay electricity debt
* Menu-driven console interface

## Technologies Used

* C Language
* Structs
* Arrays
* Functions
* Sorting (qsort)

## Project Purpose

This project was created to practice C programming concepts such as data structures, functions, arrays, sorting, and console-based system design.

## How It Works

Users can manage student records and debt information through a simple command-line menu.
